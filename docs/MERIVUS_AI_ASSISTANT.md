# Merivus AI 悬浮助手

## 功能概览

Merivus AI 悬浮助手是地面站内置的轻量交互入口，不依赖浏览器或 VSCode 扩展机制。入口固定在主窗口右下角，切换到飞行视图、计划视图、设置页或参数页时都会保留。

当前版本提供三类能力：

- 基础问答：说明当前支持的指令范围和参数说明能力。
- 快捷飞行指令：支持“1号起飞10米”“2号降落”“全部返航”“暂停”等文本指令。
- 参数说明辅助：在“设置 -> 参数”页面鼠标悬停参数行时显示参数元数据说明。
- 外部 Agent 接入入口：可配置本机 HTTP Agent 端点，将自然语言问题交给大模型/MCP 服务解析。
- 会话管理：支持清空当前聊天记录，并设置保留最近消息数量。

## 安全边界

AI 面板不会直接把自然语言发送到 MAVLink。文本会先被解析为结构化意图，涉及起飞、降落、返航、暂停等飞行动作时，面板会生成待确认命令，用户确认后才调用现有 `Vehicle` 控制接口。

当前版本刻意不处理复杂坐标、航线点、区域框选等任务。这类操作仍建议通过地图鼠标交互完成，避免自然语言坐标描述带来的歧义。

## 交互行为

- 右下角悬浮气泡是全局组件，挂载在 `MainRootWindow.qml`，因此切换飞行、计划、设置、参数等页面时不会销毁。
- 气泡未聚焦时会降低透明度并贴近右下角，鼠标悬浮时高亮展开。
- 展开的 AI 面板是右侧抽屉样式，默认覆盖右侧工作栏的上下区域，便于在飞行视图和设置页之间保持连续会话。
- 面板左边缘提供水平拖拽手柄，顶部和底部提供垂直拖拽手柄，可在本机保存宽度、高度和上边距偏好。
- 面板右上角“配置”可打开 Agent、模型、端点和历史保留设置。

## 支持的快捷指令

示例：

- `查看状态`
- `1号起飞10米`
- `UAV-2 降落`
- `全部返航`
- `3号暂停`

飞行器选择规则：

- `全部`、`所有`、`all` 表示当前在线全部飞行器。
- `1号`、`UAV-1` 表示指定编号飞行器。
- 未指定编号时默认使用当前活动飞行器。

## 参数说明来源

参数说明直接来自 QGroundControl 现有 Fact 元数据：

- `shortDescription`
- `longDescription`
- 当前值、默认值、单位
- 最小值、最大值
- 枚举项
- 飞控或地面站重启要求

PX4/APM 参数元数据已经由项目内置 XML 加载，因此该功能不需要联网查询参数文档。

## 外部 Agent / 大模型部署

推荐把大模型和 MCP 工具放在地面站外部的本机服务中，而不是直接把 API Key 写进 QML。AI 面板通过 HTTP 调用本机 Agent，Agent 再负责调用 OpenAI、本地模型、MCP 服务或任务编排框架。

默认配置：

- 端点：`http://127.0.0.1:8765/merivus/agent`
- 方法：`POST`
- Content-Type：`application/json`

请求示例：

```json
{
  "message": "1号起飞10米",
  "model": "gpt-4.1-mini",
  "fleet": "UAV-1：未解锁，模式 Hold，高度 0.0 m，电量 90%",
  "history": [
    { "role": "user", "content": "查看状态" },
    { "role": "assistant", "content": "UAV-1：未解锁，模式 Hold，高度 0.0 m，电量 90%" }
  ]
}
```

响应示例：

```json
{
  "reply": "我已识别为起飞请求，需要你确认后才会下发。",
  "intent": {
    "action": "takeoff",
    "vehicleIds": [1],
    "altitude": 10
  }
}
```

`intent.action` 当前只允许以下白名单：

- `takeoff`
- `land`
- `rtl`
- `pause`

即使外部 Agent 返回了飞行动作，面板也只会生成“待确认命令”，用户点击确认后才调用现有 `Vehicle` 控制接口。坐标点、航线、区域、参数写入等高风险动作建议后续单独设计强约束 schema、仿真校验和二次确认流程。

## 消息记录管理

- 点击 AI 面板右上角“配置”，可设置“消息保留”数量。
- 点击“清空历史”会清空当前会话记录，并保留一条欢迎说明。
- 当前实现是轻量会话管理，不把完整聊天记录持久化到磁盘；这样可以减少敏感任务信息和飞行上下文长期留存。
- 后续如果需要持久化，建议落到单独的加密日志文件或数据库，并增加“按任务归档、导出、删除、保留天数”等策略。

## 相关文件

- `custom/res/Merivus/MerivusAIAssistantPanel.qml`：AI 悬浮气泡和右侧聊天面板。
- `custom/res/Merivus/ai-nine-star.svg`：AI 悬浮入口使用的九芒星图标。
- `custom/res/Merivus/MainRootWindow.qml`：全局挂载 AI 助手，保证页面切换后仍保留。
- `src/QmlControls/ParameterEditor.qml`：参数行 hover 说明卡片。
- `custom/qgroundcontrol.qrc`：注册 AI 助手 QML 资源。
- `custom/res/Merivus/qmldir`：导出 AI 助手 QML 类型。

## 后续扩展建议

后续接入 LLM/MCP 时，建议仍保留当前安全边界：LLM 只负责生成结构化意图，真正执行动作仍由地面站白名单命令服务和用户确认流程控制。
