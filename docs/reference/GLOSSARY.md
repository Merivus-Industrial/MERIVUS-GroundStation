# 术语表

| 术语 | 含义 |
| --- | --- |
| FTC | Fault-Tolerant Control，容错控制相关子系统。本项目当前包含观测、影子分配和恢复候选，不等同于主动接管。 |
| uORB | PX4 内部发布/订阅消息总线。 |
| MAVLink 方言 | 在上游消息集合上增加产品消息的 XML 定义及生成头文件。 |
| FactGroup | QGroundControl 将 Vehicle 遥测组织为 QML 可访问属性的对象。 |
| OBSERVE | 只观测。 |
| SHADOW | 计算候选执行器分配，但不下发。 |
| CANDIDATE | 恢复状态机产生候选设定值，但不下发。 |
| ACTIVE | 明确接入执行器命令路径。当前固件不报告。 |
| 控制裕度 | 在当前效能矩阵与饱和约束下估计的可用控制能力。 |
| 健康分数 | 电机观测器给出的当前状态分数，不是剩余寿命。 |
| stale | 曾收到数据，但超过契约超时未更新。界面必须显示 N/A。 |
| N/A | 数据不可用、未接收、过期或协议不兼容；不能用 0 代替。 |
| LOC | Loss of Control，失控状态或风险。 |
| 影子分配 | 与现有控制并行计算、只用于观测和评估的分配结果。 |
| 恢复候选 | 尚未连接到执行器命令路径的恢复状态或设定值。 |
| GitNexus | 本地代码图索引工具；用于结构定位和影响提示，不替代 Qt/QML 运行验证。 |
