# MERIVUS `0.1.0-dev.1` 阶段性初版

发布日期：2026-07-17

版本性质：开发测试版（Development Preview）

## 版本定位

`0.1.0-dev.1` 是 MERIVUS 系统首次阶段性汇总版本，用于固定当前代码、界面、Local Agent、安全策略、构建方式和文档基线。该版本不是正式发行版，不承诺生产稳定性，也不授权 AI 执行真实飞行动作。

## 已纳入范围

- 基于 QGroundControl 的 MERIVUS 定制构建、品牌资源和主界面。
- 多机列表、遥测状态、地图交互、环境姿态与视频区域。
- 全局 AI 悬浮气泡和可自由缩放的 AI 聊天面板。
- 聊天消息记录、清空历史、Provider 配置与 Agent 状态展示。
- Python Local Agent、Mock / Ollama Provider、HTTP 契约和模型评估。
- QGC C++ Agent 客户端、进程监管、Schema 校验、本地风险策略和审计事件。
- Windows 构建与 Agent 打包脚本、自动化测试、架构和安全文档。

## 本阶段最新交互改进

- AI 面板首次布局使用响应式宽高并保存用户后续拖拽结果。
- 左、上、下缩放边缘独立高亮，拖拽坐标相对全局面板稳定计算。
- 消息气泡区分用户与助手角色，增加轻量悬浮反馈、边缘强调和更舒适的文本间距。
- 输入区改为统一命令栏样式，聚焦与悬浮状态更清晰。
- Agent Supervisor 可在开发目录自动发现 Python 或打包后的 Agent。

## 验证基线

- Agent 自动化测试与 QGC AI 本地策略测试已建立。
- QML 资源生成和语法检查通过。
- Windows Qt 5.15.2 / MSVC Release 增量构建已通过，产物为 `staging/MERIVUS.exe`。
- 尚未执行真实飞行、真实 MAVLink 全链路、生产网络、签名安装包或长期稳定性测试。

## 明确限制

- `flight_execution_enabled=false`。
- `ActionProposal` 只用于显示和预览，不能视为动作执行结果。
- 未实现 MCP、云端设备网关、用户鉴权、数据库、Media Service、GIS Safety Service 和真实命令执行器。
- 所有真实飞行相关验证必须经过人工安全评审，并优先在 Mock、回放或 PX4 SITL 环境中进行。

## 后续版本方向

下一阶段建议使用 `0.1.0-dev.2`，重点处理稳定构建、SITL 回归、AI 会话持久化策略、参数解释数据源和受控确认框架；在安全策略、审计和仿真验证完成前，不开放 AI 自动飞行动作。
