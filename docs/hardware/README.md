# MERIVUS 硬件文档索引

本目录用于记录项目硬件资料的本地来源和用途。厂商原始 PDF 是否允许公开分发尚未确认；在确认授权前，不应自动提交原始 PDF 到公开仓库。

| 文件名 | 厂商/模块 | 用途 | 来源 | 公开分发状态 |
| --- | --- | --- | --- | --- |
| `HyperLTE_4G_Module.pdf` | HyperLTE 4G 图数传一体模块 | 记录 4G 数传、图传、TCP/RTSP 端口、供电和接线要求 | 用户提供的本地厂商资料 | 待确认 |
| `Hyper982_RTK_Module.pdf` | Hyper982 RTK 成品模块 / UM982 核心器件相关资料 | 记录 RTK UART/USB、RTCM/NMEA、波特率、输出频率和供电接口要求 | 用户提供的本地厂商资料 | 待确认 |

## 使用原则

- 架构文档引用硬件信息时，必须区分“硬件手册确认”和“用户描述但尚未验证”。
- HyperLTE 与 Hyper982 的供电参数必须分开记录，禁止混用。
- 接线前必须以实际成品模块接口标识、硬件版本和厂商最新确认信息为准。
- Codex 不得自动修改真实硬件参数，不得自动运行真实无人机测试。

## Git 建议

如果本仓库会公开发布，建议将本地厂商原始 PDF 加入 `.gitignore`，仅提交本 README 和必要的可公开摘要。是否忽略 PDF 需由项目负责人确认后再修改 `.gitignore`。
