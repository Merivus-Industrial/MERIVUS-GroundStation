## HyperLTE 4G 图数传一体模块

### 从硬件手册中确认

来源：`docs/hardware/HyperLTE_4G_Module.pdf`

- 模块面向无人机、无人车、无人船等移动平台。
- 支持 UART、LAN 等通信接口。
- 支持 ArduPilot、PX4、INAV 及其他 MAVLink 协议飞控。
- 使用 4G 网络时存在一定延迟和卡顿，手册要求谨慎飞行/驾驶。
- QGC 可通过 TCP 连接服务器。
- 数传端口规则为 `62***`，具体端口以数传模块卡槽处为准。
- 图传端口规则为 `52***`，具体端口以数传模块卡槽处为准。
- 示例 RTSP 地址：`rtsp://119.45.168.211:52121/stream=0`，手册标注仅作实例。
- 地面站不需要部署 4G 软件，通过 TCP 连接。
- HyperLTE 模组供电电压为 5-36V。
- 为避免电调导致电压电流波动，强烈建议使用 12V 稳压模块供电，最好给图数传系统配备独立 12V 工作电源。
- PX4 示例中，数传连接飞控串口波特率设置为 57600，协议为 MAVLink2。

### 用户描述但尚未验证

- 当前实际 QGC TCP Link：
  - 服务器地址：`119.45.168.211`
  - 当前实际数传端口：`62178`
- 无桨叶实机测试中：
  - QGC 可接收飞控数据。
  - QGC 可下发简单命令。
  - 使用鼠标执行起飞等简单操作时电机会响应。
  - 这只说明基础 MAVLink 上下行链路成立，不等于完整飞行安全验证通过。

### 当前架构要求

- `119.45.168.211` 和端口必须作为外部配置，不写死在业务代码中。
- 控制链路和视频链路逻辑分离。
- 视频失败、卡顿或重连不得阻塞 MAVLink 心跳。
- 4G 链路测试默认只能用 Mock、SITL 或回放；真实飞机测试需要人工授权。

## Hyper982 RTK 模块

### 从硬件手册中确认

来源：`docs/hardware/Hyper982_RTK_Module.pdf`

- 支持 Dual-RTK 双 RTK 引擎。
- 支持差分输入 RTCM 3.x。
- 数据格式包含 NMEA-0183。
- 具备 UART x3、USB x1。
- USB 口对应模块串口 2；修改串口 2 波特率会影响 USB 口波特率。
- 示例配置：
  - `config com1 230400`
  - `config com2 230400`
  - `config com3 230400`
  - `gpgga com1 0.05`
  - `gpths com1 0.05`
  - `gphdt com1 0.05`
  - `gprmc com1 0.05`
  - `UNIHEADINGA com1 1 0.05`
  - `AGRICA com1 1 0.05`
- 示例中 `0.05` 秒间隔对应 20Hz。
- 手册建议常用波特率为 115200 或 230400，常用 230400。
- 文档中对无人机使用建议输出 5Hz-10Hz，不要超过 20Hz。
- UM982 核心器件电源范围为 3.0V-3.6V DC。
- Hyper982 成品模块 VCC 接口范围为 3.6V-6.0V，推荐 5.0V。
- 不得将 12V 直接输入 Hyper982 成品模块 VCC。
- Hyper982 接线前必须核对实际成品模块接口标识、硬件版本和厂商最新确认信息；本文档不替代厂商最新电气规格。

### 用户描述但尚未验证

- 当前阶段 Hyper982 主要作为定位数据源，不单独承担通信服务器功能。
- 当前无人机未安装机载电脑。

### 当前架构要求

- QGC 第一版只读取和展示已有 GPS/RTK 状态，不直接重新配置 RTK 硬件。
- `230400` 和 `20Hz` 作为硬件配置要求记录，不随意写入飞控或 RTK。
- RTK 丢失时只告警和降级，不让 AI 臆测位置。
- 在任何 RTK 接线或配置操作前，必须完成硬件版本、输入电压、串口电平、波特率和飞控接口确认。
- Codex 不得自动修改真实 RTK 或飞控硬件参数。

## 机载电脑评估

### 已知事实

- 用户描述当前无人机没有安装机载电脑。
- 当前基础能力不强制依赖机载电脑：
  - MAVLink 遥测。
  - 参数读取。
  - 模式切换。
  - 任务上传。
  - 基础远程指令。
  - 图数传模块自身的视频编码和转发。

### 当前建议

当前阶段不引入 ROS、树莓派或机载电脑。

只有以下需求成熟后再评估机载电脑：

- 机载 YOLO。
- 视觉定位。
- 机载避障。
- 目标跟踪。
- 断网后的复杂自主任务。
- USB/CSI 摄像头编码。
- 本地缓存和断点续传。
- 复杂多传感器融合。
